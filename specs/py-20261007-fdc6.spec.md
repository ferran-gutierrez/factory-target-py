# Ruff line length 140

- **REQ-1** `pyproject.toml` defines `[tool.ruff]` with `line-length = 140` and includes the same non-length Ruff settings currently declared in the repository root `ruff.toml` (`target-version`, `src`, and `[tool.ruff.lint] select`) so Ruff can resolve the full project configuration from `pyproject.toml` alone.
  `[@test] ../tests/test_ruff_line_length.py`

- **REQ-2** From the repository root, `python -m ruff check --show-settings .` reports `linter.line_length` equal to `140`.
  `[@test] ../tests/test_ruff_line_length.py`

- **REQ-3** From the repository root, `python -m ruff format --check .` exits with code `0` on the repository tree used by factory CI after the line-length change.
  `[@test] ../tests/test_ruff_line_length.py`

- **REQ-4** A single-line Python statement containing exactly 130 ASCII characters (excluding shebang and encoding cookies) is accepted by `python -m ruff format --check` on that file when the file lives under `src/` or `tests/`.
  `[@test] ../tests/test_ruff_line_length.py`

## Assumptions

- The request targets the factory CI commands `ruff check .` and `ruff format --check .` with no extra CLI flags; line length must come from project configuration files, not per-invocation overrides.
- Ruff 0.16.x resolves `line-length` from root `ruff.toml` when both `ruff.toml` and `pyproject.toml` exist in the same directory; `pyproject.toml` alone is insufficient until `ruff.toml` is aligned (for example `line-length = 140` or `extend = "pyproject.toml"` with length removed from `ruff.toml`).
- Updating root `ruff.toml` is required for REQ-2 through REQ-4 but that path is listed under `contract.paths.checkDefinitions` and is outside `contract.paths.allowed` for implement stations; applying the `ruff.toml` change is expected as part of delivering this task on the branch, not via edits under `src/**` or `tests/**` alone.
- Existing source already satisfies format at 100 characters; widening to 140 does not require reformatting existing files unless a line between 101 and 140 characters is intentionally added to satisfy REQ-4.
