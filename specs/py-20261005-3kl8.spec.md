# Top expense categories

- **REQ-1** Running `python -m factory_target_py.expenses` with a readable expense CSV and `--top N`, where `N` is a positive decimal integer, adds a `top_categories` entry to the successful JSON output containing an array of objects with exactly `category` and `total` fields.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-2** Each `top_categories` object uses the expense category name and its total from the same category totals used by the output, with `total` encoded as a string formatted with exactly two digits after the decimal point.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-3** When `--month YYYY-MM` and `--top N` are both supplied, `top_categories` is built from category totals restricted to the selected month, consistently with the `category_totals` output for that month.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-4** `top_categories` contains at most `N` categories, ordered by total descending and then by category name ascending using plain string comparison, so uppercase letters sort before lowercase letters when totals tie.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-5** When `N` is larger than the number of categories, `top_categories` contains every available category, and when there are no categories it is an empty array.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-6** The CLI accepts `--top N` only when `N` consists of one or more decimal digits and represents a positive integer; zero, negative values, values containing a decimal point, and other text cause a clear error message on stderr, no stdout output, and exit status 1.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-7** When `--top` is not supplied, successful and error output remains exactly as defined by the existing expenses CLI behavior, without a `top_categories` entry.
  `[@test] ../tests/test_expenses_cli.py`

## Assumptions

- The `--top` option follows the existing order-independent optional-flag parsing behavior and may be combined with `--month` and `--budgets`.
- The invalid-value error text is not prescribed by the request; the implementation will use a concise clear message identifying `--top` and requiring a positive decimal integer.
- No changes to public importer or budget-alert APIs are required; the summary is derived from the already selected CLI category totals, and runtime dependencies remain standard-library only.
