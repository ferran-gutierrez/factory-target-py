# Expense CLI top categories

- **REQ-1** Running `python -m factory_target_py.expenses <csv-file> --top N` with a valid positive decimal-digit integer `N` adds a `top_categories` property to the JSON output containing an array of at most `N` objects, each with `category` equal to a category key from the displayed `category_totals` and `total` equal to that category total formatted as a string with exactly two decimal places.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-2** `top_categories` orders entries by total descending and, when totals are equal, by category name using plain string comparison, so uppercase letters sort before lowercase letters; the totals are computed from the same category totals displayed by the command.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-3** When `N` is greater than the number of displayed categories, `top_categories` contains every displayed category, and when the displayed category totals are empty, `top_categories` is an empty array.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-4** When `--month YYYY-MM` is supplied with `--top N`, `top_categories` is built from the category totals filtered to that month and contains no categories from other months.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-5** When `--top` is supplied without a following value, with zero, with a negative number, with a number containing a decimal point, or with any other non-decimal-digit text, the CLI writes a clear error message to stderr, writes nothing to stdout, and exits with status 1.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-6** When `--top` is not supplied, the CLI JSON output is exactly unchanged from the existing behavior for the same expense CSV and existing optional flags, including omission of `top_categories`.
  `[@test] ../tests/test_expenses_cli.py`

## Assumptions

- `N` is parsed as one or more ASCII decimal digits (`0` through `9`) and must represent an integer greater than zero; invalid values use the clear error message `invalid --top value`.
- The `--top` option may be combined with the existing `--month` and `--budgets` options, and the displayed category totals after month filtering are the source for the top-category summary.
- Top-category money values use the existing two-decimal `Decimal` JSON formatting behavior, and category names retain the canonical spelling already present in `category_totals`.
- Runtime code uses only the Python standard library; no new dependencies or console entry points are required.
