# Supported expense categories

- **REQ-1** The module `factory_target_py.expenses` defines a callable `get_expense_categories` that accepts no arguments.
  `[@test] ../tests/test_expense_categories.py`

- **REQ-2** `factory_target_py.get_expense_categories` is importable from the package root and refers to the same callable as `factory_target_py.expenses.get_expense_categories`.
  `[@test] ../tests/test_expense_categories.py`

- **REQ-3** `get_expense_categories()` returns a `list` whose elements are all `str`.
  `[@test] ../tests/test_expense_categories.py`

- **REQ-4** `get_expense_categories()` returns exactly `["travel", "meals", "supplies", "software", "other"]` in that order.
  `[@test] ../tests/test_expense_categories.py`

- **REQ-5** Each call to `get_expense_categories()` returns a new list instance (mutating the returned list does not change the canonical categories).
  `[@test] ../tests/test_expense_categories.py`

## Assumptions

- Category values are lowercase English slug strings; the canonical set and order are fixed in REQ-4 and are not configurable at runtime.
- The function lives in a new `expenses` module and is re-exported from `factory_target_py.__init__` for a stable public import path.
- No persistence, I/O, or network access is involved; categories are defined in source code using the standard library only.
