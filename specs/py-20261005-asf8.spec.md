# Expense CLI output formats

- **REQ-1** Running `python -m factory_target_py.expenses` with a readable expense CSV and no `--format` option uses JSON output by default and produces exactly the same JSON payload, formatting, errors, month filtering, budget alerts, and exit status as the existing CLI behavior.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-2** Running the expenses CLI with `--format json` and a readable expense CSV produces the same output as omitting `--format`, including when `--month` or `--budgets` is also supplied; the input file being read results in exit status 0 even when imported rows produce validation errors.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-3** Running the expenses CLI with `--format csv` and a readable expense CSV writes to stdout a CSV document whose first line is exactly `category,total`, followed by one line per category from the selected totals, ordered by ascending category using plain case-sensitive string comparison, with each line containing the category and its total formatted as a two-decimal string using the same money formatting as JSON output.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-4** When `--format csv` is combined with `--month YYYY-MM`, the CSV category totals contain only valid expense rows in that selected month, while the input CSV is still fully imported so every validation error is reported.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-5** In CSV format, each import validation error is written to stderr as exactly one line in the form `line <n>: <reason>`, using the same line number and reason as the corresponding JSON error, no JSON is written to stdout, and the process exits with status 0 after the expense input file is read.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-6** If `--format` is supplied without a value or with a value other than `json` or `csv`, the CLI writes a usage message to stderr, writes nothing to stdout, and exits with status 1 without reading the expense file.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-7** The `--format` option can be supplied alongside `--month` and `--budgets` in any option order, and duplicate or otherwise malformed option usage is treated as a usage error with no stdout output and status 1.
  `[@test] ../tests/test_expenses_cli.py`

## Assumptions

- The CSV format contains category totals only; it does not include month totals, budget alerts, or a separate errors section.
- CSV category ordering uses Python-style plain string comparison of the canonical category keys emitted by the selected totals, so uppercase letters sort before lowercase letters; this is intentionally different from case-insensitive budget-alert ordering.
- JSON remains the sole default format and all existing JSON behavior remains authoritative when `--format` is absent or explicitly set to `json`.
- The `--format` option is an optional CLI flag and may appear in any order with the existing `--month` and `--budgets` options.
- Runtime code uses the Python standard library only; no new third-party dependencies are required.
