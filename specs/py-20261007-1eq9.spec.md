# Expense CLI top categories

- **REQ-1** Running `python -m factory_target_py.expenses` with a readable expense CSV and `--top` followed by a valid positive integer `N` prints JSON that includes a `top_categories` key whose value is a JSON array of at most `N` objects, each with string keys `category` and `total`.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-2** Each `top_categories` entry’s `category` is a canonical category name and its `total` is a two-decimal string equal to the value for that same category key in the printed `category_totals` object (for example when `category_totals` is `{"Food": "12.30"}`, a top entry is `{"category": "Food", "total": "12.30"}`).
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-3** `top_categories` is built only from the same category totals map used for `category_totals` in that run, so when `--month YYYY-MM` is also supplied the ranking uses month-filtered totals (not full-file totals).
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-4** `top_categories` is ordered by descending `total` (compared as decimal money, consistent with the underlying totals); when two categories share the same total, their order is ascending by `category` using plain lexicographic string comparison (Unicode code point order, so for example `"Banana"` sorts before `"apple"` because uppercase `B` precedes lowercase `a`).
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-5** When the number of categories in `category_totals` is greater than `N`, `top_categories` contains exactly `N` entries; when it is less than or equal to `N`, it contains one entry per category; when there are no categories, `top_categories` is an empty array.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-6** A `--top` value is invalid if it is not a non-empty string of ASCII decimal digits (`0`–`9`) with no sign, whitespace, or decimal point, or if it parses to an integer that is not strictly greater than zero; for invalid values (including `0`, negative integers written with a leading minus, values containing a decimal point such as `1.5`, and non-numeric text) the CLI writes a clear error message to stderr, prints nothing to stdout, and exits with status code `1`.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-7** Running `python -m factory_target_py.expenses` with `--top` as the last argument (no value following) writes a usage message to stderr and exits with a non-zero code.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-8** When `--top` is not supplied, successful CLI JSON omits the `top_categories` key and all other keys and values match the behaviour immediately before this task for the same expense CSV and optional `--month` and `--budgets` inputs.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-9** Optional `--month`, `--budgets`, and `--top` flags may appear in any order after the expense CSV path; equivalent flag sets produce the same `category_totals`, `top_categories`, and (when present) `budget_alerts` for the same files.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-10** When `--top` is supplied twice or combined with duplicate `--month` or `--budgets` flags, the CLI writes a usage message to stderr and exits with a non-zero code.
  `[@test] ../tests/test_expenses_cli.py`

## Assumptions

- Supersedes py-20261004-6bjo REQ-13: optional `--month` and/or `--budgets` on the expense CLI becomes optional `--month`, `--budgets`, and/or `--top N` with JSON including `top_categories` when `--top` is present
- Supersedes py-20261004-6bjo REQ-14: usage error on bad positional count, missing or invalid `--month`/`--budgets`, or unrecognized options becomes the same plus missing `--top`, duplicate optional flags, and a separate clear stderr error (not usage) for invalid `--top` numeric values
- Supersedes py-20261004-16e2 REQ-14: usage error on bad positional count or invalid `--month`/`--budgets` becomes the same plus missing `--top`, duplicate optional flags, and a separate clear stderr error for invalid `--top` numeric values
- Supersedes py-20261005-mwft REQ-5: without `--month`, CLI JSON unchanged from before the month task becomes without `--top`, CLI JSON unchanged from before this task (no `top_categories` key) for the same inputs
- Supersedes py-20261005-mwft REQ-9: `--month` and `--budgets` in any order becomes `--month`, `--budgets`, and `--top` in any order
- Valid `--top` values use only ASCII digits with no leading sign; strings such as `007` parse as the integer `7` and are accepted when that integer is positive.
- Invalid `--top` error text is a single clear line on stderr (wording is implementation-defined but must not be empty and must not be a Python traceback).
- Usage strings shown for CLI misuse may list `[--top N]` alongside existing optional flags; exact wording is not contractually fixed beyond existing usage-message patterns.
- `pyproject.toml` cannot gain console script entry points; the CLI remains `python -m factory_target_py.expenses`.
- Runtime code uses the Python standard library only; no new third-party dependencies.
