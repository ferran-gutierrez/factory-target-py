# Top expense categories CLI summary

- **REQ-1** Running `python -m factory_target_py.expenses` with a readable expense CSV and `--top N` prints JSON containing a `top_categories` array whose objects have exactly `category` and `total` keys, where each `total` is the corresponding category total formatted as a string with exactly two decimal places.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-2** When `--top N` is supplied together with `--month YYYY-MM`, `top_categories` is built from the same category totals filtered to that month, so an expense CSV with `Food` totaling `5.00` in `2024-03` and `7.00` in `2024-04` produces `top_categories` containing only `{"category": "Food", "total": "7.00"}` for `--month 2024-04 --top 1`.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-3** `top_categories` orders categories by total descending and, for equal totals, by category name ascending using plain string comparison, so categories `apple` and `Banana` with equal totals are ordered `Banana` then `apple`.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-4** `top_categories` contains no more than N category objects and includes the first N categories in the required ordering, so categories created out of total order with `--top 2` produce exactly the two highest-ranked categories.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-5** When N is larger than the number of categories, `top_categories` contains every category, and when the selected totals contain no categories, `top_categories` is an empty array.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-6** The `--top` value is valid only when it is a positive integer represented solely by decimal digits; for `0`, a negative number, a value containing a decimal point, or any other text, the CLI writes a clear error message to stderr, writes nothing to stdout, and exits with status 1.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-7** Without `--top`, the CLI JSON output is exactly unchanged from the existing behavior and does not include a `top_categories` entry.
  `[@test] ../tests/test_expenses_cli.py`

## Assumptions

- `--top N` is an order-independent optional flag alongside the existing `--month` and `--budgets` flags, and supplying it more than once is a usage error.
- Plain string comparison for tie-breaking uses Python string ordering, so upper-case letters sort before lower-case letters.
- The clear invalid-value error may use the CLI's existing usage/error style as long as it identifies that `--top` requires a positive decimal integer; the process exits with status 1 and emits no stdout.
- Top-category totals use the existing two-decimal `Decimal` JSON formatting and preserve the existing expense canonical category spelling.
- End-to-end tests are out of scope because `contract.e2e.applies` is false; CLI behavior is covered by unit-style subprocess tests under `tests/`.
- Runtime code uses the Python standard library only; no new third-party dependencies.
