# Expense CLI output format

- **REQ-1** When `--format` is omitted or `--format json` is supplied, a readable expense CSV produces the same successful stdout JSON (keys, filtered totals, `errors`, optional `month` and `budget_alerts`) and exit code 0 as before this task for the same `--month` and `--budgets` arguments.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-2** When `--format csv` and the expense CSV path is readable, stdout contains only CSV text whose first line is exactly `category,total`, followed by one line per entry in the filtered `category_totals` map (after `--month` filtering when that flag is present), ordered by ascending category name using plain string comparison (Unicode code points, so uppercase letters sort before lowercase), each data line `<category>,<total>` where `<category>` is the canonical category key and `<total>` is the same two-decimal string that would appear in JSON `category_totals` for that category.
  `[@test] ../tests/test_expenses_cli_format.py`

- **REQ-3** When `--format csv` and the imported expense CSV yields one or more validation errors, stderr contains exactly one line per error of the form `line <n>: <reason>` using the same integer `line` and string `reason` as each object in the JSON `errors` array for that import, stdout still follows REQ-2 (including the header line when there are no categories), no JSON is printed to stdout, and the process exit code is 0 because the expense file was read successfully.
  `[@test] ../tests/test_expenses_cli_format.py`

- **REQ-4** When `--format csv` and filtered `category_totals` includes both `Banana` and `apple` (expense-first canonical keys that order as `apple` then `Banana` under case-insensitive comparison but as `Banana` then `apple` under plain string comparison), stdout CSV data lines list `Banana` before `apple`.
  `[@test] ../tests/test_expenses_cli_format.py`

- **REQ-5** When `--format` is present but not followed by a value, or when the value after `--format` is neither `json` nor `csv`, the CLI writes a usage message to stderr, prints nothing to stdout, and exits with status 1.
  `[@test] ../tests/test_expenses_cli_format.py`

- **REQ-6** Optional `--format` may appear in any order with `--month` and `--budgets` after the expense CSV path; for example `--format csv --month 2024-04` and `--month 2024-04 --format csv` produce the same CSV category totals for the same files.
  `[@test] ../tests/test_expenses_cli_format.py`

- **REQ-7** When `--format csv` is supplied together with `--month YYYY-MM`, only spending in that calendar month contributes to the CSV category totals, matching the `category_totals` object printed under `--format json` for the same inputs.
  `[@test] ../tests/test_expenses_cli_format.py`

- **REQ-8** When `--format` appears more than once on the command line, the CLI writes a usage message to stderr, prints nothing to stdout, and exits with status 1.
  `[@test] ../tests/test_expenses_cli_format.py`
