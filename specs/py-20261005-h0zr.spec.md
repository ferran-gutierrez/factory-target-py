# Expense CLI top categories summary

- **REQ-1** Running `python -m factory_target_py.expenses` with a readable expense CSV and `--top N` prints successful JSON containing a `top_categories` array of at most `N` objects, where each object has exactly `category` and `total` fields and `total` is the corresponding category total formatted as a string with exactly two decimal places.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-2** The `top_categories` entries are built from the same category totals represented by the output's `category_totals`, so when `--month YYYY-MM` is also supplied they include only totals for that selected month.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-3** `top_categories` entries are ordered by descending numeric total, and entries with equal totals are ordered by ascending category name using plain case-sensitive string comparison where uppercase letters sort before lowercase letters.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-4** When `N` is larger than the number of categories, `top_categories` contains every available category exactly once.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-5** When `--top N` is supplied and the selected data contains no categories, the successful JSON contains `top_categories` set to an empty array.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-6** `N` is valid only when it consists solely of decimal digits and represents a positive integer; zero, negative values, decimal-point values, and other text cause the CLI to write a clear validation error to stderr, write nothing to stdout, and exit with status 1.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-7** Without `--top`, the CLI JSON output is exactly unchanged from the existing behavior, including omission of the `top_categories` key, whether or not `--month` or `--budgets` is supplied.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-8** The `--top N` option can be supplied together with the existing optional CLI flags in any order, and successful output preserves the existing `category_totals`, `month_totals`, `errors`, `month`, and `budget_alerts` behavior.
  `[@test] ../tests/test_expenses_cli.py`

## Assumptions

- `--top` is parsed as an order-independent optional flag alongside `--month` and `--budgets`, and it may appear at most once.
- Leading zeroes are accepted when the `--top` value consists of decimal digits and represents a positive integer, such as `01`.
- The validation error uses the CLI's existing usage/error style and explicitly identifies the invalid `--top` value; its exact wording is not otherwise part of the contract.
- Runtime code continues to use only the Python standard library; no new dependency or console-script entry point is required.
