# Expense CLI top categories

- **REQ-1** Running `python -m factory_target_py.expenses` with a readable expense CSV and `--top` followed by a valid positive integer `N` prints success JSON that includes a `top_categories` key whose value is a JSON array of at most `N` objects, each with string keys `category` and `total` where `total` is formatted with exactly two digits after the decimal point.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-2** Each object in `top_categories` uses the same `category` string key and the same `total` string value as the printed `category_totals` map for that category (after any `--month` filtering applied to `category_totals`).
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-3** `top_categories` is ordered by descending numeric value of each entry’s `total` string (compared as exact two-decimal money amounts); when two categories share the same total, their objects appear in ascending order of the `category` string using plain lexicographic comparison (for example totals both `"15.00"` for categories `Travel` and `food` yield `[{"category": "Travel", "total": "15.00"}, {"category": "food", "total": "15.00"}]` because `"Travel" < "food"` in plain string order).
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-4** When `--top` is not supplied, successful CLI JSON omits `top_categories` and every other key and value matches the behaviour immediately before this task for the same expense file and the same optional `--month` and `--budgets` inputs.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-5** When `--top N` is supplied and `N` is greater than or equal to the number of categories in the printed `category_totals` map, `top_categories` lists every category in sort order (for example three categories with `--top 10` returns three entries).
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-6** When `--top N` is supplied and the printed `category_totals` map is empty, `top_categories` is an empty JSON array and the process still exits 0 on success.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-7** When both `--month YYYY-MM` and `--top N` are supplied, `top_categories` is built only from the filtered `category_totals` for that month; for example rows `2024-03-15,Food,Lunch,5.00` and `2024-04-01,Travel,Trip,20.00` with `--month 2024-04 --top 2` yield `"category_totals": {"Travel": "20.00"}` and `"top_categories": [{"category": "Travel", "total": "20.00"}]` with no `Food` entry.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-8** When `--top` is followed by a value that is not a positive integer written in decimal digits (including `0`, a negative integer such as `-3`, a value containing a decimal point such as `2.5`, or non-numeric text such as `abc`), the CLI writes a clear error message to stderr that identifies the invalid `--top` value, prints nothing to stdout, and exits with status code 1.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-9** Running `python -m factory_target_py.expenses` with `--top` as the last argument (no value following), a second `--top` flag, or an unrecognized optional token after the expense CSV path writes a usage message to stderr, prints nothing to stdout, and exits with a non-zero code.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-10** Optional `--top`, `--month`, and `--budgets` flags may appear in any order after the expense CSV path; for example `expenses.csv --top 2 --month 2024-05` and `expenses.csv --month 2024-05 --top 2` produce identical success JSON for the same files.
  `[@test] ../tests/test_expenses_cli.py`

## Assumptions

- A `--top` value is valid when it is a non-empty string of ASCII decimal digits with no sign or decimal point and its integer value is strictly greater than zero (so `01` and `007` are valid with numeric values 1 and 7).
- Invalid `--top` values use a dedicated stderr error line (not the generic usage line) that includes the rejected value or states that `--top` requires a positive integer; `--top` without a following value, duplicate `--top`, and unrecognized optional tokens still use the usage message pattern like other CLI misuse.
- `top_categories` includes only categories present in the printed `category_totals` object (not budget-only categories with no spending).
- Sorting by descending total compares the underlying `Decimal` totals before JSON string formatting; tie-breaking uses Python’s default string ordering on category names (`str` comparison).
- Usage text shown on misuse includes `--top` alongside existing optional flags; `pyproject.toml` cannot gain console script entry points and the CLI remains `python -m factory_target_py.expenses`.
- Runtime code uses the Python standard library only; no new third-party dependencies.
