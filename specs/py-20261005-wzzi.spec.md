# Expense CLI top categories

- **REQ-1** Running `python -m factory_target_py.expenses` with a readable expense CSV and no `--top` flag prints success JSON whose keys are exactly those defined by earlier expense CLI requirements for the same optional `--month` and `--budgets` inputs (no `top_categories` key).
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-2** Running `python -m factory_target_py.expenses` with a readable expense CSV and `--top` followed by a positive integer `N` prints success JSON that includes a `top_categories` key whose value is a JSON array of objects, each with string keys `category` and `total` where `total` is formatted with exactly two digits after the decimal point.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-3** Each `top_categories` entry uses the same canonical `category` string and spending total as the corresponding entry in the printed `category_totals` map for that run (after `--month` filtering when `--month` is supplied); for expense rows `2024-05-01,Travel,A,20.00`, `2024-05-02,Food,B,8.00`, and `2024-05-03,Rent,C,15.00`, `--top 2` yields `"top_categories": [{"category": "Travel", "total": "20.00"}, {"category": "Rent", "total": "15.00"}]` (not `Food` first despite file order).
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-4** `top_categories` is ordered by descending `total` (compared as decimal money, not as strings); when two categories share the same total, the entry with lexicographically smaller `category` appears first; for categories `Beta` and `Alpha` each totaling `10.00`, `--top 2` lists `Alpha` before `Beta`.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-5** When `--top` is followed by `0`, a value that parses as a negative integer, or a token that is not a base-10 positive integer (for example `abc` or `2.5`), the CLI writes a clear error message to stderr, exits with a non-zero code, and prints no success JSON to stdout.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-6** When `--top N` is valid and `N` is greater than the number of distinct categories in the printed `category_totals`, `top_categories` lists every category in ranked order (length equals the category count); for three categories with positive totals and `--top 10`, the array length is 3.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-7** When `--month YYYY-MM` and `--top N` are both supplied, ranking uses only categories and totals from the filtered `category_totals` for that month (same scope as REQ-2 and REQ-3 of the month-filter spec); spending in other months does not affect `top_categories`.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-8** Running `python -m factory_target_py.expenses` with `--top` as the last argument (no value following), a duplicate `--top` flag, or an unrecognized optional argument writes a usage message to stderr and exits with a non-zero code.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-9** Optional `--month`, `--budgets`, and `--top` flags may appear in any order after the expense CSV path; the same files and flag values produce the same `category_totals`, optional `budget_alerts`, and `top_categories` regardless of flag order.
  `[@test] ../tests/test_expenses_cli.py`
