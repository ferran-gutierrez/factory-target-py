# Top categories CLI summary

- **REQ-1** Running `python -m factory_target_py.expenses` with a readable expense CSV and no `--top` flag prints success JSON that does not include a `top_categories` key and otherwise matches the CLI behaviour defined before this task for the same expense file and any other optional flags (`--month`, `--budgets`).
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-2** Running `python -m factory_target_py.expenses` with a readable expense CSV and `--top` followed by a positive integer `N` prints success JSON that includes `top_categories`, a JSON array of exactly `min(N, C)` objects where `C` is the number of distinct expense canonical categories in the `category_totals` map used for that output (after any `--month` filter), each object having string keys `category` and `total`, with `total` formatted as a two-decimal money string consistent with `category_totals` values.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-3** Each `top_categories` entry lists one category from that output’s `category_totals` and its `total` equals the corresponding `category_totals` value; the array is ordered by descending numeric total (comparing the underlying `Decimal` sums, not string order) and, when two categories share the same total, by ascending lexicographic order on the expense canonical `category` string (for example categories `Travel` and `Food` both totaling `20.00` appear as `Food` then `Travel`, not `Travel` then `Food`).
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-4** When `--top N` is supplied and `N` is strictly greater than the number of categories in the relevant `category_totals` map, `top_categories` lists every category exactly once (for example three categories with distinct totals and `--top 10` yields a three-element array ordered by total descending).
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-5** Running `python -m factory_target_py.expenses` with `--top` followed by `0`, a negative integer (for example `-1`), or a value that is not a positive integer in decimal form (for example `abc` or `2.5`) writes a clear error message to stderr that identifies the invalid `--top` value, exits with a non-zero code, and prints no success JSON to stdout.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-6** When `--month YYYY-MM` and `--top N` are both supplied, `top_categories` is computed from the same filtered `category_totals` map printed in JSON for that month (not from full-file category totals); for example rows `2024-03-01,Food,A,50.00` and `2024-04-01,Travel,B,100.00` with `--month 2024-03 --top 1` yield `top_categories` containing only `Food` with total `"50.00"`.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-7** When `--budgets` and `--top N` are both supplied on success, printed JSON includes both `budget_alerts` and `top_categories` with `top_categories` still derived from the printed `category_totals` map (month-filtered when `--month` is present).
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-8** Running `python -m factory_target_py.expenses` with `--top` as the last argument (no value following), a second `--top` flag when one was already parsed, or an unrecognized optional token after the expense CSV path writes a usage message to stderr and exits with a non-zero code without success JSON on stdout.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-9** Optional `--month`, `--budgets`, and `--top` flags may appear in any order after the expense CSV path; for example `--top 2 --month 2024-05 --budgets budgets.csv` and `--budgets budgets.csv --month 2024-05 --top 2` produce the same filtered totals, alerts, and `top_categories` ordering for the same input files.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-10** When the expense CSV path or (with `--budgets`) the budgets CSV path cannot be read, or when `--budgets` is used and `parse_budgets_csv` raises `ValueError` after a successful read, CLI stderr and exit-code behaviour remains as defined in prior expense CLI specs regardless of whether `--top` was also supplied; invalid `--top` values are rejected before reading files when `--top` appears with its value in the argument list.
  `[@test] ../tests/test_expenses_cli.py`
