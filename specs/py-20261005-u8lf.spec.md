# Top categories expense summary

- **REQ-1** Running `python -m factory_target_py.expenses` with a readable expense CSV and `--top N`, where `N` is a positive decimal integer, prints a successful JSON object containing `top_categories` as an array of objects with exactly the string field `category` and the two-decimal money string field `total`, while retaining the existing output fields.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-2** The `top_categories` entries are built from the same category totals as the rest of the output and are ordered by descending total and then by ascending category name using plain string comparison; for categories `Alpha` with `5.00`, `beta` with `10.00`, and `gamma` with `10.00`, `--top 3` outputs `beta`, `gamma`, then `Alpha`.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-3** When `N` is smaller than the number of categories, `top_categories` contains at most the first `N` categories in the required ordering, and when `N` is larger than the number of categories, it contains every category exactly once.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-4** When the expense data has no valid categories, a successful invocation with `--top N` includes `top_categories` as an empty array.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-5** When `--month YYYY-MM` and `--top N` are both supplied, `top_categories` is computed from only the category totals for the selected month; categories from other months are not included.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-6** When `--top` is supplied without a following value, or with zero, a negative number, a value containing a decimal point, or any other non-decimal-digit text, the CLI writes a clear error message to stderr, writes nothing to stdout, and exits with status 1.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-7** When `--top N` is not supplied, the successful CLI JSON output is exactly unchanged from the existing behavior and does not include a `top_categories` entry.
  `[@test] ../tests/test_expenses_cli.py`

## Assumptions

- `--top` is an order-independent optional flag like `--month` and `--budgets`, may appear at most once, and accepts one following token.
- A valid `--top` value consists only of ASCII decimal digits and is converted to an integer; values that do not fit in memory are handled by the normal Python integer and JSON list behavior.
- The top-categories summary is added only to successful JSON output when `--top` is present; existing error handling and all output not related to `--top` remain unchanged.
- Top-category totals use the existing two-decimal JSON money formatting, and category names retain the canonical spelling already present in the selected category totals.
- End-to-end tests are out of scope because `contract.e2e.applies` is false; CLI behavior is covered by unit-style subprocess tests under `tests/`.
