# Top categories CLI summary

- **REQ-1** Running `python -m factory_target_py.expenses` with a readable expense CSV and `--top` followed by a valid positive integer `N` prints JSON that includes a `top_categories` key whose value is a JSON array of at most `N` objects, each with string keys `category` and `total`.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-2** Each `top_categories` entry’s `category` is a category name from the printed `category_totals` object and its `total` is the same two-decimal money string as the value for that category in `category_totals` (for example when `category_totals` is `{"Food": "30.00", "Travel": "50.00"}`, a `--top 2` summary lists `Travel` with `"50.00"` before `Food` with `"30.00"`).
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-3** When `--month YYYY-MM` is also supplied, `top_categories` is built from the same filtered `category_totals` shown in the JSON for that month (not from full-file category totals); for rows with `Food` `5.00` in `2024-03` and `Food` `7.00` in `2024-04`, `--month 2024-04 --top 1` yields `"top_categories": [{"category": "Food", "total": "7.00"}]`.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-4** `top_categories` is ordered by descending `total` (comparing the two-decimal money strings as exact `Decimal` values, equivalent to numeric order for normalized totals); when two categories share the same total, they are ordered by ascending `category` using plain Python string comparison on the category name (ASCII lexicographic order, so an upper-case letter sorts before a lower-case letter in the same position).
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-5** When categories `Rent` and `Travel` each total `50.00` and `Food` totals `80.00`, `--top 3` lists `Food` first, then `Rent` before `Travel` (because `"Rent" < "Travel"` as strings).
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-6** When categories `Apple` and `apple` each total `10.00` and no other categories exist, `--top 2` lists `Apple` before `apple`.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-7** When `N` is greater than the number of categories in the displayed `category_totals`, `top_categories` includes every such category in the order required by REQ-4 through REQ-6.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-8** When the displayed `category_totals` object is empty (for example `--month` selects a month with no valid rows), `--top N` still succeeds with `"top_categories": []`.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-9** Running `python -m factory_target_py.expenses` with a readable expense CSV and no `--top` flag prints JSON that omits the `top_categories` key and is otherwise identical to CLI output before this task for the same CSV and optional `--month` and `--budgets` arguments.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-10** When `--top` is followed by a value that is not a positive integer written with ASCII decimal digits only— including `0`, a negative integer such as `-1`, a value containing a decimal point such as `1.5`, or non-digit text such as `abc`—the CLI writes at least one clear, non-empty line to stderr describing the invalid `--top` value, prints nothing to stdout, and exits with status 1.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-11** A `--top` value is valid when it consists only of ASCII decimal digits and its numeric value is greater than zero (for example `3` and `03` are valid; `0` is not).
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-12** Optional `--top`, `--month`, and `--budgets` flags may appear in any order after the expense CSV path; the same files and flag values produce the same `category_totals` and `top_categories` regardless of flag order.
  `[@test] ../tests/test_expenses_cli.py`
