# Expenses top categories summary

- **REQ-1** Running `python -m factory_target_py.expenses <csv-file> --top N` with a valid positive decimal-digit integer `N` adds a `top_categories` JSON array containing at most `N` objects, each with `category` and `total` keys, where `total` is a two-decimal string.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-2** The `top_categories` entries use the same category totals as the other CLI output and therefore reflect `--month YYYY-MM` filtering when that option is supplied.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-3** `top_categories` entries are ordered by descending total, and entries with equal totals are ordered by category name using plain string comparison so uppercase letters sort before lowercase letters.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-4** When `N` is larger than the number of categories, `top_categories` contains every available category, and when the selected totals contain no categories it is an empty array.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-5** The CLI rejects `--top` values that are zero, negative, contain a decimal point, or contain any non-decimal-digit text by writing a clear error message to stderr, writing nothing to stdout, and exiting with status 1.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-6** Without `--top`, the successful CLI JSON output is exactly unchanged from the existing behavior and does not include a `top_categories` key.
  `[@test] ../tests/test_expenses_cli.py`

## Assumptions

- `--top` is an optional flag whose following argument is required, and it may appear in either order relative to the existing `--month` and `--budgets` flags.
- Positive decimal-digit validation means the argument consists only of ASCII digits and represents an integer greater than zero; leading zeroes are accepted.
- Top-category totals are serialized with the same two-decimal money formatting as `category_totals`.
- The existing CLI usage and error behavior for missing values, duplicate flags, unknown flags, unreadable files, invalid budgets, and invalid months remains unchanged unless directly required by `--top` validation.
- Runtime code uses the Python standard library only; no new third-party dependencies are required.
