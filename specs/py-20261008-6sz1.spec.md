# Ruff line length 140

- **REQ-1** The repository root `ruff.toml` sets `line-length = 140` (replacing the previous `100` value) and leaves all other keys in that file unchanged from their values on the branch before this task (`target-version`, `src`, and the `[lint]` `select` list).
  `[@test] ../tests/test_ruff_line_length.py`

- **REQ-2** Running `python -m ruff check --show-settings` with the repository root as the working directory reports `linter.line_length = 140` and `formatter.line_width = 140`.
  `[@test] ../tests/test_ruff_line_length.py`

- **REQ-3** `python -m ruff check` on a Python file under `tests/` that contains one logical line of exactly 139 ASCII characters (for example a module-level string assignment whose source line is 139 characters long and uses only `#` padding) completes with exit code 0 and does not report `E501` for that line; the same line lengthened to 141 characters in a sibling fixture file reports `E501`.
  `[@test] ../tests/test_ruff_line_length.py`

- **REQ-4** After the configuration change, `python -m ruff format --check .` run from the repository root exits with code 0 (the same command the factory `format` check uses).
  `[@test] ../tests/test_ruff_line_length.py`

- **REQ-5** After the configuration change, `python -m ruff check .` run from the repository root exits with code 0 (the same command the factory `lint` check uses).
  `[@test] ../tests/test_ruff_line_length.py`

## Assumptions

- Effective Ruff line length for this project is configured only in root `ruff.toml`; when that file exists, Ruff ignores `[tool.ruff]` in `pyproject.toml`, so setting line length via `pyproject.toml` is out of scope and cannot satisfy this request.
- The factory `pyproject.toml` sensitive rule forbids adding tool settings there; this task does not change `pyproject.toml` dependency lists or any other project metadata.
- Implementing REQ-1 requires editing `ruff.toml`, which the specify-stage input contract lists under `checkDefinitions`; the implement stage is expected to permit that single configuration edit for this task so CI `ruff check .` and `ruff format --check .` use the updated limit.
- Only the numeric line-length limit changes to 140; no new Ruff rules, ignores, or formatter options are introduced.
- No runtime package behaviour under `src/factory_target_py/` changes; expense importer and CLI requirements from earlier specs remain unchanged.
