# Top expense categories

- **REQ-1** Running `python -m factory_target_py.expenses <csv-file> --top N` with a valid positive decimal-digit integer `N` prints a successful JSON object containing a `top_categories` array in addition to the output fields produced without `--top`.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-2** Each object in `top_categories` has exactly the keys `category` and `total`, where `category` is the category-total map key and `total` is the corresponding amount formatted as a string with exactly two digits after the decimal point.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-3** `top_categories` is built from the same category totals shown in the output, contains at most `N` categories, and orders entries by total descending; when totals are equal, it orders category names by plain string comparison, where upper-case letters sort before lower-case letters.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-4** When `--month YYYY-MM` and `--top N` are both supplied, `top_categories` uses only the category totals for the selected month and follows the existing month-filtered output, including an empty array when the selected month has no categories.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-5** When `N` is larger than the number of categories, `top_categories` contains every category exactly once, preserving the required ordering.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-6** When the selected expense data has no categories, a valid `--top N` produces `"top_categories": []` and exits successfully.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-7** A `--top` value is valid only when it consists entirely of decimal digits and represents a positive integer; zero, negative values, values containing a decimal point, and other text cause a clear error message on stderr, no stdout output, and exit status 1.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-8** Without `--top`, the CLI output is exactly unchanged from the existing behavior for the same expense file and any existing `--month` or `--budgets` options; no `top_categories` field is added.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-9** `--top N` can be supplied alongside the existing optional flags in either order after the expense CSV path, and each flag's existing behavior remains unchanged.
  `[@test] ../tests/test_expenses_cli.py`

## Assumptions

- `--top` is parsed as an optional flag after the positional expense CSV path, consistent with the existing `--month` and `--budgets` flags; duplicate `--top` flags are treated as usage errors.
- The clear invalid-value error is a single non-empty stderr line identifying the `--top` argument, with no traceback; the exact wording is left to the implementation.
- Category names retain the canonical spelling already present in the filtered `category_totals` map, and money formatting follows the existing two-decimal CLI serialization.
- No new runtime dependencies or changes outside the contract's allowed paths are required.
