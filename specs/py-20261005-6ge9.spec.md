# Expense top categories summary

- **REQ-1** Running `python -m factory_target_py.expenses` with a readable expense CSV and `--top N` where `N` is a positive decimal integer prints a successful JSON object containing `top_categories` as an array of at most `N` objects, each with exactly `category` and `total` keys; each `total` is the corresponding category total formatted as a string with exactly two decimal places.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-2** The `top_categories` entries are built from the same category totals represented by the output’s `category_totals`, so when `--month YYYY-MM` is also supplied they include only categories and amounts from that selected month.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-3** `top_categories` entries are ordered by total descending, and entries with equal totals are ordered by category name ascending using plain string comparison where uppercase letters sort before lowercase letters.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-4** When `N` is larger than the number of categories, `top_categories` contains every category, and when the selected or unfiltered category totals contain no categories, `top_categories` is an empty array.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-5** The `--top N` option is accepted alongside the existing optional `--month` and `--budgets` options in any order after the expense CSV path, and successful output retains the existing fields and behavior while adding `top_categories`.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-6** `N` is valid only when it consists solely of one or more ASCII decimal digits and represents an integer greater than zero; zero, negative values, values containing a decimal point, and all other text are invalid.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-7** For an invalid `--top` value or a missing value after `--top`, the CLI writes a clear error message containing `invalid --top value` to stderr, writes nothing to stdout, and exits with status 1.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-8** When `--top` is not supplied, the CLI JSON output is exactly unchanged from the existing behavior, including omission of the `top_categories` field.
  `[@test] ../tests/test_expenses_cli.py`

## Assumptions

- The `--top` option may be supplied at most once; duplicate options are treated as invalid CLI usage.
- Existing `money_to_json_string` formatting is reused for `top_categories.total`, including its current two-decimal rounding behavior.
- The option accepts the same order-independent flag style as `--month` and `--budgets`; no new runtime dependency or console-script entry point is needed.
