# Expense CLI top categories

- **REQ-1** When `--top N` is supplied with a readable expense CSV, the CLI prints a successful JSON object containing a `top_categories` entry whose value is an array of objects with exactly `category` and `total` fields, and each `total` is a two-decimal money string.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-2** `top_categories` is calculated from the same category totals represented by the output's `category_totals`; therefore, when `--month YYYY-MM` is also supplied, it contains only categories and amounts from that selected month.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-3** The `top_categories` array is ordered by total descending, and ties are ordered by category name ascending using plain string comparison, where upper-case letters sort before lower-case letters.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-4** The `--top` value is valid only when it consists of one or more ASCII decimal digits and represents a positive integer; zero, negative values, values containing a decimal point, and other text are rejected.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-5** When `--top` is missing its value or has an invalid value, the CLI writes a clear error message to stderr, writes nothing to stdout, and exits with status 1.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-6** When `N` is larger than the number of category totals, `top_categories` contains every category exactly once, and when there are no category totals it is an empty array.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-7** Without `--top`, the CLI output is byte-for-byte unchanged from the behavior defined by the existing expense CLI requirements, including when `--month` and/or `--budgets` are supplied.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-8** The `--top` option can be supplied alongside `--month` and/or `--budgets` in any order accepted for the existing optional flags, and a successful invocation exits with status 0.
  `[@test] ../tests/test_expenses_cli.py`

## Assumptions

- Supersedes py-20261005-mwft REQ-5: When `--month` is not supplied, successful CLI JSON keys and values match the behaviour before this task for the same expense and optional `--budgets` inputs becomes When neither `--month` nor `--top` is supplied, successful CLI JSON keys and values match the behaviour before this task for the same expense and optional `--budgets` inputs.
- `--top` is parsed as an optional flag like the existing `--month` and `--budgets` flags; repeated `--top` flags are usage errors.
- The top-category summary is added only when `--top` is present; its category names preserve the canonical names already used in `category_totals`.
- Top-category selection is performed after month filtering and before JSON serialization, using the exact `Decimal` totals already used for `category_totals`; money strings use the existing two-decimal serialization rules.
- A clear invalid-option error may use the CLI's existing usage-error format, as long as it is written only to stderr and the process exits 1.
- Runtime code uses the Python standard library only; no new third-party dependencies are required.
