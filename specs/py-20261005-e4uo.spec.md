# Expense CLI top categories

- **REQ-1** Running `python -m factory_target_py.expenses` with a readable expense CSV and `--top` followed by a positive integer written only with decimal digits (no sign, no decimal point) prints JSON that includes a `top_categories` key whose value is a JSON array of at most that many objects, each with string keys `category` and `total` where `total` is the same two-decimal money string as the matching entry in `category_totals` for that category name.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-2** Each `top_categories` entry is built from the same category totals map shown in `category_totals` in the printed JSON (after any `--month` filtering), not from unfiltered import totals.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-3** `top_categories` is ordered by descending numeric total (comparing the underlying amounts, not lexicographic string order on `total`), and when two categories share the same total, by ascending `category` using plain string comparison (Unicode code point order, so an upper-case letter sorts before a lower-case letter in the same position).
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-4** When the requested `N` is greater than the number of categories present in `category_totals`, `top_categories` lists every category with spending in that map (fewer than `N` objects).
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-5** When `category_totals` is empty (for example after `--month` selects a month with no valid rows), successful JSON with `--top N` still includes `top_categories` as an empty array.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-6** When `--top` is not supplied, successful JSON omits the `top_categories` key and every other key and value matches the behaviour defined before this task for the same expense file and the same optional `--month` and `--budgets` inputs.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-7** When `--top` is followed by `0`, a negative integer, a value containing a decimal point, or any text that is not a non-empty string of decimal digits representing a positive integer, the CLI writes a clear error message to stderr (not the generic usage line), writes nothing to stdout, and exits with status code 1.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-8** Optional `--top`, `--month`, and `--budgets` flags may appear in any order after the expense CSV path; for the same files and flag values, permutations such as `--top 2 --month 2024-05` and `--month 2024-05 --top 2` produce identical `category_totals`, `top_categories`, and other JSON fields.
  `[@test] ../tests/test_expenses_cli.py`
