# Expense CLI top categories

- **REQ-1** When `--top` is not supplied, successful CLI JSON omits the `top_categories` key and matches the same keys and values as before this task for the same expense CSV path and any combination of optional `--month` and `--budgets` flags.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-2** When `--top` is followed by a valid positive integer `N`, the printed JSON includes a `top_categories` key whose value is a JSON array of at most `N` objects, each with string keys `category` and `total`, where `total` is formatted with exactly two digits after the decimal point.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-3** Each `top_categories` entry uses the same `category` string and the same two-decimal `total` string as the corresponding entry in the printed `category_totals` object for that run (after any `--month` filtering applied to `category_totals`).
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-4** `top_categories` is ordered by descending numeric total (comparing the underlying amounts, not lexicographic order of the formatted strings); when two categories share the same total, the one whose `category` string is smaller under plain Python string comparison (`<`) appears first (uppercase letters sort before lowercase letters in ASCII).
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-5** When at least three distinct categories have totals `10.00`, `10.00`, and `5.00` in the printed `category_totals`, `--top 3` yields a `top_categories` array whose first two objects share `"total": "10.00"` and list the tied categories in ascending plain string order (for example `Banana` before `apple` when both total `10.00`), followed by the third category with the lower total.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-6** When `N` is greater than the number of categories in `category_totals`, `top_categories` lists every category once, still ordered per REQ-4.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-7** When `category_totals` is empty (for example after `--month` selects a month with no valid rows) and `--top` is supplied with a valid `N`, the printed JSON includes `"top_categories": []`.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-8** When `--top` is followed by a value that is not a positive integer written in decimal digits only (including `0`, a negative numeral such as `-1`, a numeral with a decimal point such as `1.5`, or non-digit text such as `abc`), the CLI writes exactly one line `invalid --top` to stderr, prints nothing to stdout, and exits with status 1.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-9** Running `python -m factory_target_py.expenses` with `--top` as the last argument (no value following) writes a usage message to stderr and exits with a non-zero code.
  `[@test] ../tests/test_expenses_cli.py`

- **REQ-10** Optional `--top`, `--month`, and `--budgets` flags may appear in any order after the expense CSV path; for example `--top 2 --month 2024-05 --budgets budgets.csv` and `--budgets budgets.csv --month 2024-05 --top 2` produce the same filtered totals, alerts, and `top_categories` ranking for the same files.
  `[@test] ../tests/test_expenses_cli.py`

## Assumptions

- Supersedes py-20261004-6bjo REQ-13: optional --month and/or --budgets flags becomes optional --month, --top N, and/or --budgets flags on the expense CLI.
- Supersedes py-20261004-6bjo REQ-14: usage error on unrecognized optional flags becomes usage error also when --top is present without a following value (invalid --top values use a dedicated error line instead of the usage message).
- Supersedes py-20261004-16e2 REQ-14: usage error on bad positional count, --budgets without path, --month without value, or invalid --month becomes the same cases plus --top without a following value.
- Supersedes py-20261005-mwft REQ-5: without --month, JSON matches pre-month-filter behaviour becomes without --month and without --top, JSON omits month and top_categories and otherwise matches behaviour before the top-categories task.
- A valid `--top` argument is a non-empty string of ASCII digits with no sign, decimal point, or surrounding whitespace, whose numeric value is at least 1 (leading zeros such as `01` are allowed and denote that integer).
- A second `--top` flag on the same invocation is treated as unrecognized optional argument misuse and yields the usage message on stderr with a non-zero exit code, consistent with duplicate `--month` or `--budgets`.
- The usage message text includes `[--top N]` alongside existing optional flags when any supported optional flag appears on the command line.
- `top_categories` totals are ranked using the same `Decimal` amounts backing `category_totals`, not by parsing the two-decimal strings.
- Runtime code uses the Python standard library only; no new third-party dependencies.
- `pyproject.toml` cannot gain console script entry points; the CLI remains `python -m factory_target_py.expenses`.
